# billsharifzade.github.io

Personal CV site for Sharifzoda Bilol — React 19 + Vite, deployed to GitHub Pages
from `main` by `.github/workflows/pages.yml`.

## Commands

```bash
npm install
npm run dev       # dev server
npm run build     # production build into dist/
npm run cv        # rebuild the CV downloads into public/cv/ (needs cargo)
npm run preview   # serve dist/ locally
npm run lint      # eslint (also gates the deploy workflow)
npm run icons     # regenerate src/data/icons.js from Font Awesome
```

## How it fits together

`src/data/cv.js` is the single source of truth for the CV: the page, the
`<noscript>` fallback, the JSON-LD `Person` schema, and all six download formats
read from it. Editing it updates everything at once.

The downloads are static files built before Vite runs (`npm run cv`, which
`predev` and `prebuild` call): `scripts/cv-json.mjs` prints the CV as JSON and
`../cvgen`, a Rust tool, writes PDF, DOCX, XLSX, CSV, Markdown and plain text
into `public/cv/` (gitignored). The page links to them directly, so a download
starts instantly and ships no exporter code. Building needs `cargo`.

The files share the site's design through `src/utils/cvTheme.js` (palette,
face, the `bill@coolest_website:~$` prompt) and `src/data/cvIcons.js`:

- **PDF** is typeset by Typst from `cvgen/src/cv.typ`, with the four JetBrains
  Mono TTFs from `src/assets/fonts/ttf` (OFL) compiled into cvgen, so it comes
  out byte-identical on any machine; its dark ground is drawn as vector and
  always prints. Section and contact glyphs are the same Font Awesome paths the
  page uses.
- **DOCX** uses the page colour (`w:background`), which Word shows on screen but
  prints only when "Print background colors and images" is enabled — the PDF is
  the print copy. Icons are PNGs rasterised by resvg.
- **XLSX** is one dark card per sheet: styled header, alternating row ground,
  gridlines off, frozen header, hyperlinked repositories.
- **TXT** is the terminal itself — prompt header, `──` rules, `›` bullets,
  wrapped at 78 columns. **MD** and **CSV** stay unstyled on purpose; they are
  the formats most likely to be pasted into someone else's system.

`npm run build` also pre-renders the page: a second, SSR build of
`src/entry-server.jsx` renders the app to HTML, and `scripts/prerender.mjs`
writes it into `dist/index.html`, which `src/main.jsx` then hydrates. Anything
that differs between server and client (pointer, clock, WebGL) mounts only after
hydration, behind `useHydrated()`.

The backdrop, `src/components/GradientASCII.jsx`, is adapted from React Bits and
cut down to the one look the site uses. It runs at 30 fps, one device pixel per
CSS pixel, and compiles its shaders in the background.

`vite.config.js` carries four build-time concerns:

- **`cv-seo-fallback`** substitutes the `<noscript>` CV, the JSON-LD block and
  the hashed font preload into `index.html`, and stamps `og.png`'s content hash
  into the social-card URL so messenger caches refresh on their own. It throws
  if a placeholder comment is missing — these were once silently stripped, which
  left the crawler fallback building to nothing.
- **`cv-seo-files`** emits `robots.txt` and `sitemap.xml`.
- **`cv-downloads`** fails the build if any of the six CV files is missing.
- **chunking** splits `react` and the animation libraries out of the app bundle,
  and keeps font subsets as real files rather than `data:` URIs (which the
  page's `font-src 'self'` CSP would block).

## Assets

Icons are inline SVG paths generated by `scripts/make-icons.mjs` from the Font
Awesome glyphs actually used: `src/data/icons.js` for the page (in the main
bundle) and `src/data/cvIcons.js` for the CV files (read at build time, never
bundled). Font Awesome is a devDependency only — shipping the webfont instead
cost 277 kB of fonts and 72 kB of CSS. To add an icon, add it to `SETS` in that
script and run `npm run icons`.

JetBrains Mono is self-hosted in `src/assets/fonts` (see `src/fonts.css`), which
removes a render-blocking third-party stylesheet and keeps the CSP tight.

`public/og.png` is the social preview card, regenerated by
`node scripts/make-og.mjs` (needs a local Chrome/Chromium).

`scripts/strip-comments.mjs` removes comments from sources without touching
anything else. It preserves the `index.html` build placeholders and lint
directives; run it with `--dry` first.
